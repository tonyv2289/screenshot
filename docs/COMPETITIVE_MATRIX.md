# Screenshot Roll Competitive Matrix
Updated: 2026-05-27

## Bottom Line

The category is real and increasingly crowded.

What is crowded:

- OCR on screenshots
- automatic categorization
- plain-language search
- generic "second brain" marketing

What is still available:

- the best iPhone-native capture loop
- trustworthy privacy-first positioning
- action extraction that turns screenshots into work
- durable context and memory, not just a searchable pile

## Platform Pressure

- Apple already gives users baseline OCR and contact actions through Live Text.
- Google already ships a true screenshot-memory product on Pixel with summaries, notes, collections, source recall, and suggested actions.
- That means `ScreenshotRoll` cannot win by saying "we read text in screenshots."

## What We Must Beat

`ScreenshotRoll` needs to be better at the parts the platform and generic competitors still do poorly:

1. iPhone-native capture
2. action extraction
3. context / memory
4. privacy-first paid utility positioning

## Required Product Pillars

### 1. iPhone-native capture

- bulk backfill through `PhotosPicker`
- zero-friction share-extension save path
- App Group inbox so the app can drain shared screenshots reliably
- background indexing so imports continue after the user leaves

### 2. Action extraction

- detect and surface links, emails, phones, dates, places, and tickers
- convert screenshots into immediate next steps, not just searchable records
- preserve clean copy/share/export paths for extracted intelligence

### 3. Context / memory

- topic and author clustering
- related-screenshot recall, not only search results
- exportable memory context for AI assistants
- user-facing "why these are connected" surfaces

### 4. Privacy-first business model

- on-device by default
- active clones and user data outside sync-folder chaos
- paid utility framing, not ad-supported content bait

## Anti-Goals

If Screenshot Roll becomes any of the following, it will be undifferentiated:

- a grid with OCR
- a generic photo-library clone
- a cloud-first "AI organize my screenshots" wrapper
- a second-brain brand with no iPhone-native capture moat

## Product Conclusion

The winning version of Screenshot Roll is:

- iPhone-first
- privacy-first
- share-sheet native
- action-oriented
- memory-aware

The losing version is:

- import-only
- search-only
- generic AI labeling
